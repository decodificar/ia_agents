# Application Tailoring Rules

## Never invent

Do not invent:

- Technologies
- Years of experience
- Responsibilities
- Projects
- Metrics
- Achievements
- Certifications
- Job titles
- Leadership experience
- Domain expertise
- Professional results

## Related experience

When a vacancy asks for a technology not explicitly documented here:

1. Check whether the user has provided additional information elsewhere in the current conversation or in updated profile material.
2. If not, do not claim professional experience with it.
3. If there is a genuinely related documented technology, explain the relationship without presenting it as direct experience.

## Resume tailoring

When tailoring a resume:

- Prioritize relevant documented experience.
- Use the vacancy's terminology naturally when it accurately describes the user's experience.
- Do not keyword-stuff.
- Do not remove relevant experience solely to force a match.
- Do not fabricate metrics.
- Keep chronology accurate.

## Application questions

For application questions:

- Use concrete examples from the professional history above.
- Prefer specific evidence over generic adjectives.
- Adapt the answer to the vacancy.
- Respect character limits.
- Never exaggerate experience.

# Important Profile Update Rule

This document is a baseline, not a permanent limit on the user's experience.

If the user later tells the assistant that they have additional experience, such as experience with a new framework, programming language, tool, project, responsibility, certification, or achievement, that information can be incorporated into the user's professional profile after being explicitly provided by the user.

When a later user-provided fact conflicts with this document, use the newer confirmed information.
